Crate rust-faf-mcp

Project context for your AI, native in Rust.

The Lineage Edition · v0.8.1

A Rust-native MCP server for FAF. It reads your IANA-registered project.faf and gives your AI the stack, the goal and who it's for, scored by the same always-33 kernel as faf-cli. One binary, stdio only.

cargo install rust-faf-mcp --version 0.8.1

FAF defines. AGENTS.md instructs. AI codes.

Install

cargo install rust-faf-mcp --version 0.8.1

Then point your MCP client at "command": "rust-faf-mcp".

npx --yes rust-faf-mcp@0.8.1

Downloads the release binary for macOS or Linux. Nothing to compile.

brew install Wolfe-Jam/faf/rust-faf-mcp
# already installed:
brew upgrade Wolfe-Jam/faf/rust-faf-mcp

macOS, pre-built.

Add it to any stdio MCP client: Claude Code, Cursor, Zed, Warp or Claude Desktop.

# Claude Code
claude mcp add faf -- npx --yes rust-faf-mcp@0.8.1

// any other client
{ "mcpServers": { "faf": {
  "command": "npx",
  "args": ["--yes", "rust-faf-mcp@0.8.1"]
} } }

Pin the version. An older rust-faf-mcp on your PATH may be an old Homebrew build.

The same scorefaf-rust-sdk's always-33 kernel gives the number faf-cli gives.

Lineage

.faf-dna is your project's birth certificate, the same file faf-cli writes. faf_init records the honest first score, faf_auto records each step up, and faf_dna shows the journey from Birth DNA to now.

faf_dna
Birth DNA  22%  →  85%  →  99%  now

Tools

Twelve tools. Ask your AI to "use FAF" and it picks the right one.

faf_autoSet up if project.faf is missing, sync CLAUDE.md, score. An existing file is left unchanged.
faf_initFirst write of project.faf from your tree. Never overwrites.
faf_scoreThe always-33 score, with what to fill next.
faf_goGuided steps to 100%.
faf_readRead project.faf with its parsed structure.
faf_syncUpdate CLAUDE.md from project.faf.
faf_agentsAuthor AGENTS.md from project.faf. Your own content outside the managed block is kept.
faf_gitAuthor a project.faf from a GitHub repo URL.
faf_dnaYour journey from .faf-dna, Birth DNA to now.
faf_discoverFind the nearest project.faf up the tree.
faf_compressCompress project.faf for tight context windows.
faf_tokensToken count at each compression level.
